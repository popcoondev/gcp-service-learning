# ネットワークとセキュリティ観点

## 初期状態

- ローカル実行のみ
- 外部公開や VPC 接続は未導入
- IAM は概念設計レベルに留める

## Cloud Run 導入時に学ぶこと

- 公開エンドポイントにするか、認証付き内部 API にするか
- HTTPS 終端とカスタムドメイン
- Serverless VPC Access Connector の要否

## Pub/Sub / Spanner 導入時に学ぶこと

- API から同期でどこまで呼ぶか
- 非同期境界をどこで切るか
- データプレーンと管理プレーンの権限分離

## VPC Service Controls 導入時に学ぶこと

- どのサービスを境界内に入れるか
- CI/CD や分析系のアクセスがどう変わるか
- 開発体験に与える影響
