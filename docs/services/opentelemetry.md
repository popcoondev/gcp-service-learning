# OpenTelemetry

## 何のために使うか

分散トレーシングやメトリクス標準化により、サービス横断の可観測性を高めるために使います。

## どのような構成で使うか

- Cloud Run アプリへ OTel SDK を組み込む
- Collector を介して Cloud Monitoring などへ送る

## このサンプル内でどこに登場するか

- 将来、Pub/Sub や Spanner を追加して経路が複雑になった段階で重要になります

## PM視点で何が難しいか

- 価値が抽象的で、導入優先度が下がりやすい
- 調査時間短縮の定量化
- 運用チームとの責任分担

## 開発者視点で何が難しいか

- トレースコンテキスト伝播
- ライブラリ選定
- 可観測性コストの管理
