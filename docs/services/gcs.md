# GCS

## 何のために使うか

注文関連の添付ファイル、監査出力、サンプルデータ配布などオブジェクト保管に使います。

## どのような構成で使うか

- API から直接アップロードするのではなく、将来的に署名付き URL や非同期連携も検討します
- ログ保管や学習用データ配置にも流用できます

## このサンプル内でどこに登場するか

- 将来拡張対象です
- README の GCP リソース関連図に登場します

## PM視点で何が難しいか

- データ分類と保持ポリシー
- 外部共有とセキュリティ統制
- 容量見積もりが後回しになりやすい

## 開発者視点で何が難しいか

- バケット権限の最小化
- オブジェクト命名規則
- イベント連携時の最終整合性理解
