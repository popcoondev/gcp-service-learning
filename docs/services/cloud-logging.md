# Cloud Logging

## 何のために使うか

注文 API の実行記録、障害調査、監査証跡を残すために使います。

## どのような構成で使うか

- Cloud Run から構造化ログを出力する
- trace ID や order ID をログに埋める

## このサンプル内でどこに登場するか

- 現在は標準ログ出力のみです
- 将来は request ID や order ID を含む構造化ログに進化させます

## PM視点で何が難しいか

- 何を監査ログとして残すべきかの定義
- 個人情報とログの境界
- 障害時の調査手順設計

## 開発者視点で何が難しいか

- ノイズを減らしつつ必要情報を残すこと
- 構造化ログ設計
- ローカルと本番のログ体験差分
