# BigQuery

## 何のために使うか

注文イベントを分析し、業務 KPI や教材用ダッシュボードを作るために使います。

## どのような構成で使うか

- Pub/Sub やバッチ経由で注文イベントを蓄積する
- Looker Studio などの可視化につなげる

## このサンプル内でどこに登場するか

- API の直接依存先ではなく、将来の分析基盤として登場します

## PM視点で何が難しいか

- 業務 KPI 定義とイベント定義のずれ
- コスト予測
- 分析基盤の責任者不在

## 開発者視点で何が難しいか

- スキーマ進化への対応
- 遅延到着データの扱い
- 本番系 API と分析系基盤の責務分離
