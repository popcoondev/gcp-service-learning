# IAM

## 何のために使うか

人とサービスに必要最小限の権限を与え、誤操作や権限過剰を防ぐために使います。

## どのような構成で使うか

- デプロイ用 SA と実行用 SA を分離する
- Pub/Sub、Spanner、Logging、Monitoring への権限を明示する

## このサンプル内でどこに登場するか

- README の IAM 関係図に登場します
- 今後サービス追加時の必須学習テーマです

## PM視点で何が難しいか

- 権限申請フローが案件開始のボトルネックになりやすい
- 最小権限と立ち上がり速度のトレードオフ
- 監査対応

## 開発者視点で何が難しいか

- 必要権限の特定
- 実行 SA と人間権限の分離
- 権限不足時のデバッグ
