# Workflows

## 何のために使うか

注文登録後の複数処理をオーケストレーションし、再試行や手順可視化をしやすくするために使います。

## どのような構成で使うか

- Pub/Sub イベントや HTTP 呼び出しをつなぎ、業務フローを可視化する
- 補償処理や承認フローを組み込む余地があります

## このサンプル内でどこに登場するか

- 将来、注文後処理を疎結合に増やす段階で登場します

## PM視点で何が難しいか

- 業務フローと技術フローが混線しやすい
- 例外処理責任の整理
- 手作業との境界設計

## 開発者視点で何が難しいか

- ステップ間のリトライ制御
- 可観測性の確保
- 長時間処理とイベント駆動設計の使い分け
