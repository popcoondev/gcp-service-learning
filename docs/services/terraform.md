# Terraform

## 何のために使うか

Cloud Run、IAM、Pub/Sub、Spanner などの構成をコード化し、再現性を高めるために使います。

## どのような構成で使うか

- 環境ごとに module と variable を分ける
- アプリコードとは別に IaC レビューを行う

## このサンプル内でどこに登場するか

- 将来拡張で `infra/` 配下を追加する想定です

## PM視点で何が難しいか

- 変更レビュー観点がアプリコードと異なる
- 運用責任者との調整
- 環境差分が複雑化しやすい

## 開発者視点で何が難しいか

- state 管理
- import / drift 対応
- module 粒度設計
