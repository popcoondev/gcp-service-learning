# GKE

## 何のために使うか

Cloud Run では表現しにくい高度な実行制御や周辺ワークロード統合が必要な場合に使います。

## どのような構成で使うか

- API 本体を GKE に載せ替える、または周辺処理だけ GKE で動かす
- Service Mesh や CronJob などの活用も候補です

## このサンプル内でどこに登場するか

- 高度化フェーズの比較教材として登場します

## PM視点で何が難しいか

- Kubernetes 運用責任を誰が持つか
- 学習コストと案件価値のバランス
- Cloud Run との棲み分け説明

## 開発者視点で何が難しいか

- マニフェストや Helm の運用
- クラスタ設計
- セキュリティパッチと運用負荷
