# Cloud Monitoring

## 何のために使うか

API の健全性、レイテンシ、エラー率を継続監視するために使います。

## どのような構成で使うか

- Cloud Run の標準メトリクスを使う
- 追加で業務メトリクスを送信する
- アラートポリシーを設定する

## このサンプル内でどこに登場するか

- 将来的な運用監視レイヤとして README の図に登場します

## PM視点で何が難しいか

- 監視項目が技術寄りに偏りやすい
- 業務影響とアラート閾値の紐付け
- 監視責任の所在整理

## 開発者視点で何が難しいか

- RED 指標と業務指標の両立
- アラート疲れの防止
- ダッシュボード設計
